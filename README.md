# Livit

A Flutter starter app for a **step-by-step video editing workflow**.

## What is implemented

The app currently includes the guided flow for building a video edit one step at a time:

1. Import video
2. Trim video
3. Add music
4. Export

This is the first foundation to build a full editor from scratch.

## Run locally

```bash
flutter pub get
flutter run
```

## Test

```bash
flutter test
```
